# クラスとメンバーへのアクセス可能性を最小限にする

## クラスのアクセスレベル
以下を考慮してクラスのアクセス修飾子を適切に設定する

- publicはそのパッケージのAPIとして他のパッケージからアクセスされる
- APIとして公開しないならパッケージプライベートにする

## メンバのアクセスレベル

- publicなクラスのメンバのアクセス修飾子は無条件でprivateにする。同じパッケージ内のモジュールに公開したい場合はパッケージプライベートにする。
    - パッケージプライベートにするなら、クラスを適切な単位に分割できないか考えてみる
- protectedの必要性はまれであるべき。 
    - protectedメンバーはクラスの公開APIの一部であり、永久にサポートされなければならない
- インスタンスフィールドはpublicにするべきではない。
