## 後で調べておきたいjavaのメモ
- PECS（Producer-Extends and Consumer-Super）
    - 上限境界ワイルドカード
        - 戻り値を上限の型にすること
        - メソッドの引数はnullのみ
    - 下限境界ワイルドカード
        - 引数のnull制約を解除できる
        - 戻り値はObject型
- Map.Entryインターフェース
- Apache Derby
    - インストール不要で使用できる
    - P303参照
- 共変性、非変性、反変性(P343)
- リフレクション(P383)
- Classクラス(P383)
- 例外
    - 検査例外
    - 非検査例外
- SPI(Service Provider Interface)
