# 数値型のデータ操作
## 小数点を切り上げる

```powershell
[Math]::Ceiling(1.44) # 2
```

## 小数点を切り下げる

```powershell
[Math]::Floor(1.44) # 1
```

## 四捨五入する

```powershell
[Math]::Round(1.4) # 1
[Math]::Round(1.5) # 2
[Math]::Round(1.4, 0) # 1 ※第2引数は切り上げ位置
[Math]::Round(1.5, 0) # 2 ※第2引数は切り上げ位置

# 第2引数は切り上げ位置が1以上の場合は、バグっているみたい
[Math]::Round(1.44, 1) # 1.4
[Math]::Round(1.45, 1) # 1.4 ※1.5でない
[Math]::Round(1.46, 1) # 1.5
```

## 絶対値を取得する

```powershell
[Math]::Abs(123) # 123
[Math]::Abs(-123) # 123
```
