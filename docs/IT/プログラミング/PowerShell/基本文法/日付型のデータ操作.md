# 日付型のデータ操作
## 現在日時の取得

```powershell
[DateTime]::Now # 2024年8月24日 16:42:40
```

## 今日日付を取得する

```powershell
[DateTime]::Today # 2024年8月24日 0:00:00 ※日時は0固定
```

## 日付型を文字列型に変換する

```powershell
[DateTime]::Now.ToString("yyyy/MM/dd") # 2024/08/24
Get-Date -Format yyyy/MM/dd            # 2024/08/24 Get-Dateコマンドレットでも同様の結果が得られる
```

[標準の日時書式指定文字列](http://msdn.microsoft.com/ja-jp/library/az4se3k1(v=vs.110).aspx)

## 指定した年月の日数を取得する

```powershell

[DateTime]::DaysInMonth(2024, 3) # 31 ※2024年3月の日数は31日
```

## うるう年かどうか判定する

```powershell
[DateTime]::IsLeapYear(2024) # True
[DateTime]::IsLeapYear(2025) # False
```

## 指定した日付の年、月、日、時、分、秒、ミリ秒、曜日部分を取得する

```powershell
$date = [DateTime]::Now
$date                   # 2024年8月24日 16:54:43 ※現在日時
$date.Year              # 2024                   ※年部分を取得
$date.Month             # 8                      ※月部分を取得
$date.Day               # 24                     ※日部分を取得
$date.Hour              # 16                     ※時部分を取得
$date.Minute            # 54                     ※分部分を取得
$date.Second            # 43                     ※秒部分を取得
$date.Millisecond       # 161                    ※ミリ秒部分を取得
$date.DayOfWeek         # Saturday               ※曜日部分を取得
```

## 日付の加減算

```powershell
<# 
以下コードは日付の加算を行う。
減算を行う場合は引数に負の値を入れると減算を行える。
#>
$date = [DateTime]::Now
$date                    # 2024年8月24日 16:54:43 ※現在日時
$date.AddYears(1)        # 2025年8月24日 16:54:43 ※年部分の加算
$date.AddMonths(1)       # 2024年9月24日 16:54:43 ※月部分の加算
$date.AddDays(1)         # 2024年8月25日 16:54:43 ※日部分の加算
$date.AddHours(1)        # 2024年8月24日 17:54:43 ※時部分の加算
$date.AddMinutes(1)      # 2024年8月24日 17:54:43 ※分部分の加算
$date.AddSeconds(1)      # 2024年8月24日 16:54:44 ※秒部分の加算
$date.AddMilliseconds(1) # 2024年8月24日 16:54:43 ※ミリ秒部分は表示されない

# ミリ秒部分は表示されない。以下のコマンドを実行すればわかる。
$date.Millisecond;$date.AddMilliseconds(1).Millisecond;
<#
161
162
#>
```
