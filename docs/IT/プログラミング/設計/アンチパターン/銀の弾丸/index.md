# 銀の弾丸
新しい技術や手法を知ると、つい使ってみたくなる。
開発現場のあらゆる問題を解決してくれそうなほど魅力的に見える。

そのような、「どんな問題でも一発で解決できる万能な方法」を銀の弾丸と揶揄する。

どんな課題があって、ある手法がその課題解決に効果的か、コスト的に問題にならないかを評価して判断する必要がある。  
設計にbestはない。常にbetterを目指す。

以下のようなものには、高コストをかけてまでがちがちに設計を組んでやる必要性はない。

- 使用があまり変更されない箇所
- 実験的に開発したプロトタイプ
- 寿命間近のサービス
