# ドメイン貧血モデルとは
データと操作がバラバラで単体では機能しないようなクラス。  
わざわざ他のクラスに初期化してもらったり、データをチェックしてもらったり、他のメソッドを呼び出さないと機能しなく、このような**安全に利用できない**クラスを **ドメイン貧血モデル（Anemic Domain Model）** と呼ぶ

## 弊害
|弊害|内容|
|-|-|
|生焼けオブジェクト|インスタンス変数が初期化されない可能性がある|
|重複実装|同じ処理がいたるところに実装される可能性がある|
|不正値の混入|バリデーションがなく不正値が混入する可能性がある|

## ドメインの完全性
データやろ実行に欠損や不整合がなく、正確な状態を維持できることを **ドメインの完全性** という。
